* 已确定的技术方向
  - 使用 Bevy 原生 glTF 导入器和场景实体；应用选择并标记参与的 primitive，插件负责数据准备、GPU 求解与输出。
  - CPU 使用 obvhs 首次建立普通、无空间分割的 BVH2；GPU 读取变形后顶点执行查询和 refit。
    bevy_cloth 显式依赖与 workspace 已有 obvhs 0.3.3 兼容的版本，不再增加另一套 BVH 构建库。
  - 第二方向实现 CPU obvhs rebuild 及 GPU 资源切换，再根据实验制定 refit/rebuild 策略；本轮不实现 GPU LBVH 构建。
  - 碰撞后端依赖当前/上一 tick 的顶点位置和索引，不依赖骨骼数据；动态位置提供者单独接入。
  - 复用已有 GPU XPBD 内核、解析形状碰撞和 GPU 直接渲染路径；既有 CPU 参考及七场景入口保持可运行。
  - 组件名和资产标记格式随对应步骤确定；本轮先做外部网格影响布料的单向碰撞。

* 粒子选择：当前实现与后续简化方法
  决定：2026-11-03。当前先使用全部渲染顶点，不做粒子降采样，不实现低模模拟网格及其渲染绑定。
  UV 等渲染拆点的物理对应与接缝连接单独处理，不将去重当作粒子降采样。

  后续优化保留以下方法，尚未实现、未选定依赖：
  - 硬约束：模拟粒子的初始位置取自原始渲染顶点；简化仅保留原端点，不新增或移动粒子初始位置。
  - 方法：受约束的边/半边折叠，同时生成粒子子集和模拟三角拓扑；保留粒子到原顶点的对应。
    用 QEM 等几何误差排序折叠候选；用局部分辨率、折叠后的边长/三角形质量、拓扑合法性和挂接/缝合关系限制折叠。
    平坦区域也需保留动态变形所需的分辨率，不能只按初始几何误差删点。
  - 候选实现：meshoptimizer 普通简化接口输出引用原顶点的新索引，支持顶点锁定及规整化；不使用更新位置的 simplifyWithUpdate。
    Regularize 不保证最大边长。若需自定义逐次折叠的硬限制，可评估 OpenMesh 半边折叠框架。
  - 接缝与边界：区分真实开口、缝合关系和 UV/材质拆点；保留关键点，普通边界按规则简化。
    不因空间接近而合并无拓扑连接的布面。
  - 渲染驱动：保留顶点直接映射粒子；其余顶点绑定模拟三角形，保存重心权重及必要的局部偏移。
    利用原拓扑区域和简化对应信息约束绑定，避免跨层误绑；端点合并记录本身不等于完整渲染绑定。
  - 评估：比较粒子/约束数、区域边长与三角形质量、绑定误差、结构保留、动态效果和求解耗时，再确定预算。
  参考：[[https://github.com/zeux/meshoptimizer#simplification][meshoptimizer 简化]]、[[https://github.com/gwihlidal/meshopt-rs/blob/master/src/simplify.rs][Rust 绑定]]、
  [[https://www.graphics.rwth-aachen.de/media/openmesh_static/Documentations/OpenMesh-10.0-Documentation/a06141.html][OpenMesh 简化框架]]。
