本文档写的是**具体步骤**：把 =../Velvet=（C++17 + CUDA + OpenGL 的 XPBD 布料 demo）迁移成 Bevy demo，
按什么顺序做、每步交付什么、怎么验收。规格与红线见 =../Velvet/AGENTS.md=（源真相地图 + §3 移植规格 +
§4 任务分解 + §5 移植正确性清单），本文件不重复推导，只补「落到本 workspace 该怎么做」。

* 原则（按优先级）
  1. **红线：求解器核心由用户亲手写**（=../Velvet/AGENTS.md= §0）。本文件里求解算法实现一律标 =[USER]=；
     agent 只做骨架 / 场景 / 渲染写回 / UI / 网格与约束生成接线 / 测试脚手架 / 文档 / 评审。
     **边界不确定时先问用户，不要默认帮写。**
  2. **正确性优先**：P0 是纯 Rust CPU 求解器，行为与源工程一致；P1（WGSL compute）后置，不阻塞 P0。
  3. **一次只动一个变量**：先用 =res=16= 的 =Cloth/Collision= 把整条链路（计时 → 求解 → 写回 → 渲染）
     跑对，再放分辨率、再放参数、最后铺 7 个场景。

* 1. 迁移规格速查（从源工程抄出的"事实"，实现时必须逐条对齐）

** 1.1 固定步长主循环（=VtClothSolverGPU.hpp::Simulate=）
   每次 1/60 s 固定步长（Bevy =FixedUpdate=）：
   #+begin_src text
     MouseGrabber.UpdateGrappedVertex()
     UpdateColliders()                     // 先更新 collider 的 curTransform/lastTransform
     CollideSDF(positions, colliders, frameTime)     // 预稳定化：改位置、不改速度（README Q1）
     for substep in 0..numSubsteps:
     PredictPositions(predicted, velocities, positions, substepTime)
     if enableSelfCollision:
     if substep % interleavedHash == 0: rebuildHash(predicted)
     CollideParticles(deltas, deltaCounts, predicted, invMasses, neighbors, positions)
     CollideSDF(predicted, colliders, positions, substepTime)
     for iter in 0..numIterations:
     SolveStretch(...); SolveAttachment(...); SolveBending(...); ApplyDeltas(...)
     Finalize(velocities, positions, predicted, substepTime)
     ComputeNormals(normals, positions, indices)
   #+end_src
   - =frameTime = fixedDeltaTime=，=substepTime = fixedDeltaTime / numSubsteps=。
   - =SolveAttachment= 内部含 Long Range Attachment；=SolveBending= 传 =substepTime=。

   | =predicted= | =Vec<Vec3>= | 预测位置 x* |
   | =velocities= | =Vec<Vec3>= | |
   | =deltas= / =deltaCounts= | =Vec<Vec3>= / =Vec<i32>= | Jacobi 累积量与计数 |
   | =invMasses= | =Vec<f32>= | 硬吸附点（restDistance == 0）置 0 |
   | =originalPositions= | =Vec<Vec3>= | 初始世界坐标，**仅用于自碰撞过滤** |
   | =stretchIndices= / =stretchLengths= | =Vec<[u32;2]>= / =Vec<f32>= | 顺序即求解顺序的遍历顺序 |
   | =bendIndices= / =bendAngles= | =Vec<[u32;4]>= / =Vec<f32>= | rest angle 源里恒 0 |

** 1.4 网格与约束生成（=Scene.hpp::GenerateClothMesh= + =VtClothObjectGPU.hpp=）
   - 网格：=clothSize = 2.0=；对 =y=0..=res= 外层、=x=0..=res= 内层依次 push
     =pos = clothSize * vec3(x/res - 0.5, -y/res, 0)=，=normal = (0,0,1)=，=uv = (x/res, y/res)=。
     **粒子索引 = push 顺序 = i = y*(res+1) + x**（局部坐标 x∈[-1,1]、y∈[-2,0]）。
   - ⚠️ 源里 index 生成用 =VertexIndexAt(x,y) = x*(res+1) + y=，与 push 顺序（y 外层）**是转置关系**，
     等价于把每个 quad 的对角线镜像。区域覆盖面不变（仍是同一片方形网格），但：
     1. 三角形绕序相反（所以源材质必须 =doubleSided=）；
     2. =GenerateBending= 用 =indices[i], [i+5], [i+2], [i+1]= 取 4 个点，配对到的三角形不同。
     → **迁移时 index 生成式原样照抄，不要"顺手修正"成自然对角线**；否则 bend 约束配对与绕序都变。
   - stretch：每个顶点向 +x、+y 邻居各一条，加每个 cell 的两条对角线（共 2 组，双向计 4 条/顶点）。
     rest length = 变换后世界坐标的距离。
   - bend：每 6 个 index（= 一个 quad）一条，索引 =(i, i+5, i+2, i+1)=，=angle = 0=。
   - attach + LRA：对每个吸附顶点建一个 slot（记录=变换后的=初始位置），
     然后**对所有粒子**加 =(particle, slot, |slotPos - p_i|)=；=restDistance == 0= 的粒子 =invMass = 0=。
   - =particleDiameter = |positions[0] - positions[1]| * particleDiameterScalar=。
   - =AddCloth=：把 =modelMatrix= 烘焙进顶点（=ApplyTransform=），随后 =actor->transform->Reset()=
     → Bevy 侧**布料实体 Transform 恒为 identity**。
   - =AddCloth= 返回 =indexOffset=，多布料共用 solver 时用它拼接 index（=SceneClothMultiple=）。

** 1.5 SDF 碰撞器（=Collider.hpp= / =VtClothSolverGPU.cuh::SDFCollider=）
   - 三种 =ColliderType=：Plane / Sphere / Cube；Cube 走 =invCurTransform= 转局部坐标，
     且角上做 rounded 处理（=margin=0.03=；=midVal = offset 中位数= 大于 -margin 时 =scalar=0.2=）。
   - =Collider::FixedUpdate= 维护 =curTransform= / =lastTransform=，=VelocityAt= 用 =lastTransform * invCurTransform=
     反推上一帧位置求速度（摩擦用）。→ Bevy 侧的等价组件必须**在 =Solver::step= 之前**更新。
   - Plane：=offset = p.y - (position.y + margin)=，< 0 则回推；Sphere：=radius = scale.x + margin=。
   - Swirl 场景里球体 =Collider::enabled = false=（只做视觉标记）→ 迁移时需保留 enabled 开关。

** 1.6 空间哈希（=SpatialHashGPU.hpp=.cu=）
   - =spacing = particleDiameter * hashCellSizeScalar=；=tableSize = 2 * numParticles=。
   - 坐标 → 格子：=(x,y,z) = floor(p / spacing)=；hash = =abs((x*92837111) ^ (y*689287499) ^ (z*283923481) % tableSize)=。
     ⚠️ C++ 的 =int= 溢出是 UB，Rust debug 下会 panic → 必须用 =i32::wrapping_mul / wrapping_xor / wrapping_rem=。
   - =cellStart= 初始化为 =0xffffffff=；=cellEnd= 由相邻 cellStart 推导（源注释里有 BUG_LOG）。
   - neighbor 收集（=CacheNeighbors_Kernel=）：
     - 距离判据：=length2(p - p_j) < cellSpacing2=；
     - **collision filtering**：=length2(orig - orig_j) > particleDiameter2= 才收（严格大于）；
     - 每个粒子的邻居从 =neighbors[id + j*numObjects]= 起写，满 =maxNumNeighbors= 直接 return；
     - 写完在第一个空槽写 =0xffffffff=。
   - =SetInitialPositions= 在 =AddCloth= 时抓一次快照 → Rust 侧 =original_positions= 必须在**烘焙变换之后**采集。

* 4. 移植正确性清单（= Velvet/AGENTS.md= §5 逐条落到 Rust/Bevy 语境）
  | # | 要点 | 我们的做法 |
  |---|---|---|
  | 1 | 世界坐标即求解结果 | 布料实体 =Transform::IDENTITY=；不要把粒子位置再乘实体变换（源 =actor->transform->Reset()= 同理） |
  | 2 | collision filtering（必做） | =original_positions= 初始距离 > =particle_diameter²= 才收邻居；快照必须在烘焙变换后采集 |
  | 3 | Jacobi 而非 Gauss-Seidel | 修正量累积到 =deltas=、除 =delta_counts= 后统一应用；**CPU 版也不要用 GS 顺序优化**，否则与源行为不一致 |
  | 4 | 预稳定化 CollideSDF | 子步循环前先做一次不写速度的 SDF 碰撞（README Q1） |
  | 5 | Long Range Attachment | attach 是"每个粒子都被每个吸附点约束"，不是只钉住那几个顶点（去掉它就变拉伸布） |
  | 6 | maxSpeed clamp 与 damping | 在 =Finalize= 内；=AddCloth= 时按 =2*pd/dt*numSubsteps= 覆写（注意覆写时机与场景参数覆盖的先后） |
  | 7 | bend rest angle = 0 | 源就是这样且 =bendCompliance= 默认 0；先 1:1 照抄再谈改进 |
  | 8 | 纹理 V 朝向 | 源 =stbi_set_flip_vertically_on_load(true)=；Bevy 侧 UV 照抄，若上下颠倒再翻 v（写进 readme 结论） |
  | 9 | 布料双面 | =StandardMaterial { double_sided: true, cull_mode: None, .. }= |
  | 10 | 浮点/整型语义 | C++ =int= 溢出是 UB → Rust 用 =wrapping_mul/xor/rem=；=% / abs / floor / copysign= 的负数与 NaN 语义逐条核对；=glm::abs= 与 Rust =f32::abs= 在 -0.0/NaN 上不同；除零要显式保护（sphere SDF 的 =diff/distance=） |
  | 11 | 法线由求解器每步重算 | 不依赖 Bevy 的法线缓存；如改用法线贴图/自动法线要单独验证 |
  | 12 | 索引转置（§1.4） | index 生成式原样照抄，不要"修正"成自然对角线（会影响绕序与 bend 配对） |
  | 13 | 哨兵与越界 | =neighbors= 空槽 =u32::MAX=；=cell_start= 初值 =!0=；写邻居时满 =max_num_neighbors= 直接返回（源 =return=）|
  | 14 | 多布料共享 solver | =num_particles= / =particle_diameter= / =max_speed= 是 solver 级状态；=index_offset= 拼接 index |
  | 15 | 系统顺序 | =FixedUpdate= 内：collider 变换更新 → 抓取更新 → =Solver::step= → Mesh 写回，=chain()= 固定顺序 |
  | 16 | 固定 dt 来源 | 用 =Time<Fixed>::delta_secs()=，不要用 =Time::delta_secs()=（源 =Timer::fixedDeltaTime=） |
