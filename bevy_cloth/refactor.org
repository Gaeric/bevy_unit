* Intro
  2026-11-05。

  目标：高性能的bevy cloth simulation插件

  第一步：tiny bevy compute shader jacobi xpbd solver

  原则：
  - 公式正确优先：明确约束含义、梯度、质量权重、激活条件与修正合并方式。
  - 数据布局利于后续优化：明确任务划分、读写归属与访问方式。

  已有项目和实现做为验证参考，不指导本轮重构，不约束两者输出一致。
* 求解器边界
  输入：粒子状态、约束关系及其参数、固定步长等执行参数。
  工作：根据这些关系计算修正，更新粒子状态。
  输出：GPU 中更新后的位置和速度，不要求创建一份新的粒子列表。

  以下属于周边支撑，不应混入最小求解核心：
  - 从 Mesh/GLB 生成粒子、约束和静止量，以及准备 GPU 输入布局。
  - 动态邻居与接触关系生成。
  - 应用时钟、暂停、单步、重置和 Bevy 实例管理。
  - 根据粒子位置计算 normal、坐标转换、渲染 Mesh 写入及可选 CPU 读回。
  - fixture、演示场景、UI、CPU 对照、专项探针和验证报告。

  求解应在gpu进行，求解关联的网格体在gpu渲染，减少数据读回cpu的损失。
* 当前约定的数据布局
** 粒子数据
   共 k 个粒子，逻辑数据包括位置、速度、逆质量等计算所需属性。
   求解中使用预测位置及必要工作区。
   具体采用哪些 buffer、字段如何打包和对齐，尚未确定。

** 扁平任务数组 ranges[m]
   ranges表示所有可以直接计算的约束，m即为约束总数，每项表示一条约束对一个目标粒子的修正计算。

   例如一条双粒子 stretch 可展开为两项，ranges中应该各个粒子均记录一次。

   这个方法或者不是最高效的方法，具体的优化方法后续继续思考。
* 预期执行流程
** 初始化
   准备粒子、ranges、粒子汇总索引，分配 values 与求解工作区。
   任务关系固定时，预先计算 dispatch 组数，不每轮重新排序或分配任务。

** 一轮约束迭代：两阶段
   阶段一：每线程计算一个贡献。
   - 当前讨论使用 workgroup_size = 64，组数为 ceil(m/64)，即整数 (m+63)/64。
   - 通过 global_invocation_id.x 得到 i；i >= m 时退出。
   - 读取 ranges[i]，按类型分支，读取本轮预测位置，写 values[i]。
   - 这一阶段不更新预测位置，不向粒子修正做并发累加。

   阶段二：每线程汇总一个粒子。
   - 组数为 ceil(k/64)，线程 p 通过 offsets/indices 读取该粒子的贡献。
   - 按讨论确定的 Jacobi 合并规则累计并更新该粒子的预测位置。
   - 无贡献粒子按规则保持状态，不出现除零。

   全部贡献计算完成后，才开始汇总应用；下一轮读取应用后的预测位置。
   阶段二不能再读取其他粒子正在被更新的位置来重新计算约束。
   两个阶段用有明确先后依赖的 dispatch 表达，不需要 CPU 中间等待或粒子读回。
   dispatch 不等于 submit；不要求每个阶段或每个模拟步单独提交。
* 选择依据与优化关注点
  用户提供的典型分布：每粒子约束数量接近，少数粒子更少。
  因此先用一个线程汇总一个粒子，不先引入多级归约或浮点原子累加。

  按类型排序使相邻线程倾向执行同一分支，优先减少 wave 内的执行差异。
  不要求各 workgroup 耗时完全一致，也不依赖它们按编号执行。
  64 是当前设计起点，不是已测得的最佳工作组大小。

  需要测量的主要成本：
  - values 每轮写出和索引读取的带宽、缓存命中。
  - 按粒子展开后，同一约束共享几何量的重复计算，尤其是 bend。
  - 各类型分支的寄存器使用及统一入口的实际代价。
  - 汇总线程的实际工作量差异与 GPU 利用率。
  - CPU 命令录制、提交与求解之外的输出成本。

* 尚待共同确定
  - stretch、bend、attachment、lra 的具体公式与参数；挂接与单边距离限制不默认混用。
  - Jacobi 贡献的加权、平均或其他合并规则，以及松弛方式。
  - 零逆质量粒子、退化几何、未激活约束的处理。
  - 是否使用 XPBD 累计 lambda；若使用，其属于物理约束的状态如何与展开任务协调。
  - ranges/values 的实际 GPU 字段布局、参数存储与访问方式。
  - 动态接触如何接入，不把固定关系数组当作覆盖全部碰撞情况的结论。
  - 独立于旧结果的公式验证用例，以及固定条件下的性能测量方法。
